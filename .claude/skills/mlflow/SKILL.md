# MLflow

## MLflowTracker context manager

All MLflow interaction goes through `src/ml/tracking/mlflow_tracker.py`:

```python
from src.ml.tracking.mlflow_tracker import MLflowTracker

with MLflowTracker(experiment_name="nba_bets_classification", run_name=run_name) as tracker:
    tracker.log_config(config.model_dump())
    tracker.log_params({"model_name": ..., "n_features": ...})
    tracker.set_tags({"task": "classification", "conference_filter": ..., "best_model": ...})
    tracker.log_metrics({"accuracy": ..., "f1": ..., "roc_auc": ...})
    tracker.log_model(model, artifact_path="model", registered_model_name="nba_classification_rf_same")
    tracker.log_artifacts(output_dir, artifact_path="visualizations")
    tracker.log_artifact(str(file_path), artifact_path="predictions")
    run_id = tracker.get_run_id()
```

For prediction runs (no model logged), pass `log_model=False`:
```python
with MLflowTracker(..., log_model=False) as tracker:
    ...
```

Always log: params (model type, feature counts, split config), metrics (accuracy, precision, recall, F1, ROC AUC), config dict, and the trained model artifact.

## Run naming convention

Format: `{config_name}-{YYYYMMDD}-{HHMMSS}-{conference_filter}`

Generated by `generate_run_name()` in `src/ml/training/experiment.py`.

## Model URI formats

| URI format | When to use | Requires registration? |
|---|---|---|
| `runs:/<run_id>/model` | Experimentation, any logged model | No |
| `models:/name/version` | Production, specific version | Yes |
| `models:/name/Production` | Production, alias-based | Yes + alias set |

## When to register models

- `register_model: true` — production candidates only
- `register_model: false` — experimental runs (use `runs:/` URIs instead)
- Registry name pattern: `nba_classification_{model_type}_{conference_filter}`

## Local tracking setup

- Tracking: local `mlflow.db` + `mlruns/` directory
- Experiment: `nba_bets_classification` (training), `nba_bets_predictions` (prediction)
